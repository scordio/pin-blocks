# ISO 9564 Format 1

!!! warning

    This format has not yet been implemented.

Defined in [ISO 9564-1:2002](https://www.iso.org/standard/29374.html), this format is constructed by concatenation of two fields: the plain text PIN field and the transaction field. The transaction field is a unique value, such as a transaction sequence number, a timestamp, or a random number. Since no account number is involved, this format should be used where no PAN is available.
