# ISO 9564 Format 4

Defined in [ISO 9564-1:2017](https://www.iso.org/standard/68669.html), this format is an extended PIN block format, constructed using two 128-bit fields of PIN and PAN data, respectively. This format is intended for use with a 128-bit block cipher such as AES, unlike formats 0 to 3, which are suited to 64-bit block ciphers such as Triple DES.
