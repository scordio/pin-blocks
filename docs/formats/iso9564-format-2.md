# ISO 9564 Format 2

!!! warning

    This format has not yet been implemented.

Defined in [ISO 9564-1:2017](https://www.iso.org/standard/68669.html), this format has been specified for use with Smart Cards. The format 2 PIN block shall be used only in an offline environment and shall not be used for online PIN verification. This PIN block is constructed by the concatenation of two fields: the plain text PIN field and the filler field.
